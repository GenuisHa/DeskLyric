# DeskLyric

**简体中文** · [English](README.en.md)

把网易云音乐 PC 版正在播放的歌词同步到小米手环多功能桌搭。DeskLyric 常驻 Windows 托盘，支持设备原生平滑滚动。网易云的声音可以继续从耳机或原来的扬声器播放。

**提示**：靠vibe coding完成，绝大部分工作由<u>Chatgpt</u>完成。使用本软件前，网易云音乐设置里的**SMTC需要提前关闭**，否则仅会显示歌名和歌手，如关闭后不能使用，请重启。

**原因**：在pc端播放网易云音乐时（因为我主要用网易云，其他音乐软件没测试过），小米手环桌搭机器人竟然无法显示，后发现网易云v3版本已经原生支持SMTC，可以实现歌手和歌名的推动显示。测试了一下在网易云上用 BetterNCM 和 InfLink-rs 插件时，桌搭也只可以显示歌名和歌手，缺少手机连接时那样的歌词显示，故启发完成了这个项目。可以实现蓝牙连接桌搭，输出设备选耳机或者其他的输出设备时，手环可以显示歌词，就不用在pc桌面开启歌词显示了。算是给这个鸡肋的桌搭增加一点看歌词的额外功能吧。

## 功能与显示模式

- 跟随网易云切歌、暂停、恢复和进度跳转。
- 支持设备原生平滑滚动，以及按播放进度更新的静态分页。
- 支持中文、英文和中英混排。前奏、歌词加载期间及无时间轴歌词时显示歌名和歌手。
- 支持自动跟随、托盘手动启停和开机自启动。显示选项自动保存，下次启动时恢复。

在 **歌词显示 → 平滑滚动（设备原生）** 模式下，可通过 **第二行内容** 切换布局。

| 第二行内容 | 第一行 | 第二行 |
| --- | --- | --- |
| 下一句歌词（双行滚动） | 当前歌词 | 下一句歌词，两行超宽时均可滚动 |
| 下一句歌词（静态预告） | 当前歌词，超宽时滚动 | 下一句歌词，按估算字宽截短后保持静止 |
| 歌名和歌手 | 当前歌词，超宽时滚动 | 歌名和歌手 |

在 **静态分页** 模式下，程序把当前歌词拆成短页，再按播放进度换页。

## 下载与使用

发布包面向 Windows 10 2004 及更新版本的 x64 电脑，内含 .NET 8 运行时。需要安装网易云音乐 PC 版，并联网获取歌词。无需安装 BetterNCM 或 InfLink-rs。

1. 打开仓库右侧的 **Releases**，在 `v1.0.0` 的附件中下载 `DeskLyric-v1.0.0-win-x64.exe`。
2. 解压到可写目录。通过蓝牙连接桌搭，确认它出现在 Windows 的音频输出设备列表里。
3. 运行 `DeskLyric.exe`，在网易云音乐 PC 版播放歌曲。DeskLyric 图标可能位于任务栏右下角的折叠区域。
4. 右键托盘图标，在 **歌词显示** 和 **第二行内容** 中选择布局。

## 工作原理

```mermaid
flowchart LR
    A[网易云本地播放日志] --> B[歌曲 ID 和播放进度]
    B -->|歌曲 ID| C[联网获取时间轴歌词]
    B --> D[按播放进度匹配歌词]
    C --> D
    D --> E[按布局编排两行文字]
    E --> F[Windows 媒体会话 SMTC]
    F --> G[蓝牙媒体信息 AVRCP]
    G --> H[桌搭显示与滚动]
```

1. **同步播放进度。** 增量读取 `%LOCALAPPDATA%\NetEase\CloudMusic\cloudmusic.elog`，提取歌曲 ID、播放状态和进度事件。播放时钟以这些事件为锚点推进。按歌曲 ID 请求 LRC 歌词，并按时间戳找到当前句和下一句。
2. **编排两行文字。** 原生滚动模式使用两行共 120 个 UTF-8 字节的保守传输预算。双行滚动时每行分配 60 字节，超长句会分段显示。静态预告另用相近字体估算显示宽度，给省略号留出空间。传输字节数与屏幕上的字宽分别计算。
3. **让桌搭自行滚动。** 程序把两行文字写入 Windows 媒体会话的标题和歌手字段，并将低音量载体音轨单独送到桌搭。Windows 通过蓝牙 AVRCP 传送媒体信息，桌搭固件负责绘制和滚动。网易云继续使用它原来的音频输出。

## 常见问题

实测组合为网易云音乐 `3.1.42.205594`、小米手环 9 和多功能桌搭固件 `3.0.3_0179.0064`。

| 现象 | 检查方法 |
| --- | --- |
| 一直等待播放记录 | 在网易云切换一首歌。日志路径不同的话，退出 DeskLyric 后修改程序目录内 `config.json` 的 `NeteaseLogPath`。 |
| 长句被截断或显示省略号 | 先确认选中了 **平滑滚动（设备原生）**。在静态预告模式下，第二行截短并保持静止是预期行为。 |
| 已选平滑滚动，长句仍不滚 | 在 Windows 音频输出列表检查是否出现名称包含「小米手环多功能桌搭」的扬声器。也可通过托盘的 **打开日志** 查找 `carrier routed to`，确认载体音轨的实际输出。 |
| 停止推送后仍显示最后一句 | DeskLyric 会结束推送。桌搭可能暂时保留上一条媒体信息，返回表情的时机取决于设备端。 |

反馈问题时可附上 Windows、网易云和桌搭固件版本，以及当时选择的显示模式。公开分享 `desklyric.log` 前请检查里面是否含有歌名或歌词。

## 从源码构建

在 Windows 安装 .NET 8 SDK，然后在仓库根目录运行。

```powershell
dotnet publish .\DeskLyric.csproj -c Release -r win-x64 --self-contained true -p:DebugType=None -p:DebugSymbols=false -o .\publish
```

输出文件为 `publish/DeskLyric.exe`。
